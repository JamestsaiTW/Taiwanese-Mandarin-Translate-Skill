# Heritage loanwords: 日語借詞與台語詞

Taiwan Mandarin keeps many **Japanese loanwords (日語借詞)** and **Taiwanese /
Hokkien (台語／閩南語) heritage terms** that are part of natural, everyday usage.
These are **not** to be "normalized" into China-style descriptive wording — doing
so makes the text sound foreign to Taiwan readers and erases real Taiwan usage.

Use this file alongside `terminology.md`. The rule of thumb:

> 若台灣慣用的是日語／台語借詞，就保留它，**不要**改寫成中國的描述性詞。
> 例：保留「便當」，不要改成「盒飯」；保留「瓦斯」，不要改成「煤氣」。

Columns:

- **English** — concept or gloss.
- **台灣用語** — the heritage term Taiwan uses.
- **來源語 / 借詞路徑** — origin language and borrowing path.
- **應避免** — the China-style descriptive form to avoid.
- **備註** — short usage note.

| --- | --- | --- | --- | --- |
| bento / lunchbox | 便當 | 日語 弁当（bentō） | 盒飯 | 台灣全民通用，便當店、火車便當皆是。 |
| gas (cooking/fuel) | 瓦斯 | 日語 ガス（gasu，源自荷蘭語 gas） | 煤氣 / 燃氣 | 瓦斯爐、瓦斯桶、瓦斯費、瓦斯行。 |
| cuisine / cooking | 料理 | 日語 料理（ryōri） | 菜品 / 菜餚（過度改寫） | 日本料理、台灣料理、料理三餐（動詞）。 |
| sashimi | 刺身 / 生魚片 | 日語 刺身（sashimi） | 生食魚片（過度描述） | 「刺身」與「生魚片」台灣皆通用。 |
| miso | 味噌 | 日語 味噌（miso） | 大醬 | 味噌湯為日常說法。 |
| izakaya | 居酒屋 | 日語 居酒屋（izakaya） | 日式酒館（失去語感） | 直接沿用日語漢字詞。 |
| signboard / billboard | 看板 | 日語 看板（kanban） | 廣告牌（依語境） | 台灣常說「大型看板」「看板人物」。 |
| sushi | 壽司 | 日語 寿司（sushi） | — | 通用。 |
| quality | 品質 | 受日語 品質 影響的用法 | 質量 | 「質量」在台灣＝物理 mass，勿混用。 |
| tatami | 榻榻米 | 日語 畳（tatami，音譯） | — | 室內鋪面，沿用音譯。 |
| part-time job | 打工 | 日語 アルバイト 概念，漢字「打工」 | 兼職（語感不同） | 台灣學生「打工」很常見。 |
| oden | 黑輪 / 關東煮 | 日語 おでん（oden，台語讀 oo-lián） | — | 「黑輪」為台語音轉，超商常見。 |
| set meal (Japanese) | 定食 | 日語 定食（teishoku） | 套餐（日式餐飲語境） | 日式餐廳菜單常用「定食」。 |
| ramen | 拉麵 | 日語 ラーメン（rāmen） | 日式湯麵（過度描述） | 台灣食文化保留「拉麵」。 |
| tempura | 天婦羅 | 日語 天ぷら（tempura） | 油炸食品（過度描述） | 日式料理用語。 |
| oji-san / uncle | 歐吉桑 | 日語 おじさん（ojisan，音譯） | 大叔 | 親切口語，台灣常用。 |
| oba-san / auntie | 歐巴桑 | 日語 おばさん（obasan，音譯） | 大媽 | 同上。 |
| motor / engine | 馬達 | 英語 motor → 日語 モーター | 電機（語境不同） | 「馬達」為日常音譯詞。 |

**重點說明**

- **便當 vs 盒飯**：台灣路徑＝「便當」（源自日語 弁当），是國民級用語；中國路徑＝「盒飯」。翻譯時保留「便當」。
- **瓦斯 vs 煤氣**：台灣家用燃氣一律稱「瓦斯」（瓦斯爐、瓦斯桶、瓦斯費）；中國稱「煤氣／燃氣」。勿改寫。
- **料理**：在台灣兼指「菜餚」與「烹調」（動詞），如「料理三餐」。屬日語借詞的自然用法，不需替換成「做菜／菜品」式改寫。
- **品質 vs 質量**：務必區分——台灣「品質」＝quality；「質量」僅用於物理學的 mass。把中國「質量（品質義）」改寫為「品質」。

## 台語 / 閩南語 heritage 詞

| English | 台灣用語 | 來源語 / 借詞路徑 | 應避免 | 備註 |
| --- | --- | --- | --- | --- |
| straightforward / generous | 阿莎力 | 台語（源自日語 あっさり assari） | 爽快（語感較弱） | 形容人乾脆、不囉嗦、付錢爽快。 |
| (truck/taxi) driver | 運將 | 台語＋日語 運ちゃん（unchan） | 司機（中性可，但「運將」更道地） | 親切稱呼司機大哥。 |
| boss | 頭家 | 台語 thâu-ke | 老闆（華語，可） | 口語親切說法。 |
| (lady) boss / shopkeeper | 頭家娘 | 台語 thâu-ke-niû | 老闆娘（華語，可） | 小吃、傳統市場常見。 |
| tasty / delicious | 好呷 | 台語 hó-tsia̍h | 好吃（華語，可） | 招牌、口語常見。 |
| mess up / blunder | 凸槌 | 台語 thut-tshê | 出錯 / 失誤（中性） | 形容臨場失誤、出包。 |
| muddle / careless mistake | 烏龍 | 台語 / 漢語 | 失誤（中性） | 「擺烏龍」＝糊塗弄錯。 |

**重點說明**

- **阿莎力（あっさり → 台語 → 華語）**：形容人個性乾脆、付錢爽快。是經由台語吸收的日語借詞，屬台灣特有口語，保留不改。
- **運將**：對計程車、貨車司機的親切稱呼，融合台語與日語「運ちゃん」。比中性的「司機」更有台灣味；對話、在地行銷可保留，正式或安全相關內容用「司機」。
- **頭家 / 頭家娘 / 好呷**：台語進入華語的常見詞，多見於小吃、傳統市場、招牌文案。正式書面可用「老闆／好吃」，但口語與在地語感場合宜保留。

## 使用原則（給翻譯／在地化）

1. **預設保留**：遇到上述台灣慣用的日語／台語借詞，預設保留，不要替換成中國描述性詞。
2. **方向性**：改寫只該朝「中國用語 → 台灣 heritage 詞」進行（盒飯→便當、煤氣→瓦斯），不該反向。
3. **語體判斷**：正式公文可改用較中性的對應（料理→菜餚、好呷→美味），但 UI、行銷、口語、對白應保留 heritage 詞的語感。
4. **避免混淆**：特別注意「品質≠質量」「土豆＝花生（見 `terminology.md`）」這類兩岸同形異義詞。
