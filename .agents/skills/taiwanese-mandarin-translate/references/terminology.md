# Cross-domain Taiwan terminology reference

Use this file when translating or localizing content **beyond software and UI** —
everyday life, food, medical, finance, legal, e-commerce, education, geography,
and online culture. It complements `vocabulary.md` (which stays the software/UI
quick glossary) by covering cross-strait wording differences in general-life
domains.

Prefer the Taiwan term when the target audience is in Taiwan. Avoid the China
term unless quoting, comparing usage, or translating content specifically about
China.

Columns in every table:

- **English** — the concept or gloss.
- **台灣用語** — the natural wording used in Taiwan.
- **應避免（中國用語）** — the China-leaning form to rewrite away from.
- **分歧原因 / 備註** — short reason or usage note.

For high-confusion or culturally loaded terms, a short **路徑說明** note follows
the table with 台灣路徑 / 中國路徑 / 例外.

- 中國路徑：「項目」廣泛涵蓋 project / program / 條目。
- 例外：UI 字串「3 items」仍可為「3 個項目」；不要盲目替換每個「項目」。

- 改寫時：程度義的「水平」→「水準」。
